# Tmuxinator 插件

本插件为 [tmuxinator](https://github.com/tmuxinator/tmuxinator) 提供自动补全,
以及常用 tmuxinator 命令的别名。

✅ 启用方式:把「tmuxinator」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 别名

| 别名  | 命令             | 说明                     |
| ----- | ---------------- | ------------------------ |
| `txs` | tmuxinator start | 启动 Tmuxinator          |
| `txo` | tmuxinator open  | 打开项目以进行编辑       |
| `txn` | tmuxinator new   | 创建项目                 |
| `txl` | tmuxinator list  | 列出项目                 |
