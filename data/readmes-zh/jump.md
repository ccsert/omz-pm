# Jump 插件

本插件让你可以通过手动添加标记(mark)在文件系统中轻松跳转。
这些标记以符号链接的形式存储在 `$MARKPATH` 目录中(默认为 `$HOME/.marks`)。

✅ 启用方式:把「jump」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 命令

| 命令                 | 说明                                                                            |
| -------------------- | ------------------------------------------------------------------------------- |
| `jump <mark-name>`   | 跳转到给定的标记                                                                |
| `mark [mark-name]`   | 用给定的名称创建标记;未提供名称时,使用当前目录的名称                          |
| `unmark <mark-name>` | 删除给定的标记                                                                  |
| `marks`              | 列出现有的标记及其指向的目录                                                    |

## 键位绑定

按下 `CTRL`+`G` 会把已输入的标记名替换为该标记的完整路径。
例如,假设有一个名为 `mymark` 的标记指向 `/path/to/my/mark`:

```zsh
$ cp /tmp/file mymark<C-g>
```

它将变成:

```zsh
$ cp /tmp/file /path/to/my/mark
```
