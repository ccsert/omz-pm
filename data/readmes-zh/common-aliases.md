# common-aliases 插件

本插件为许多常用命令创建实用的快捷别名。

✅ 启用方式:把「common-aliases」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 别名

### ls 命令

| 别名  | 命令         | 说明                                                                        |
| ----- | ------------ | --------------------------------------------------------------------------- |
| l     | `ls -lFh`    | 以长列表形式列出文件,显示大小、类型,大小人类可读                           |
| la    | `ls -lAFh`   | 以长列表形式列出几乎所有文件,显示大小、类型,大小人类可读                   |
| lr    | `ls -tRFh`   | 递归列出文件并按日期排序,显示类型,大小人类可读                             |
| lt    | `ls -ltFh`   | 以长列表形式按日期排序列出文件,显示类型,大小人类可读                       |
| ll    | `ls -l`      | 以长列表形式列出文件                                                        |
| ldot  | `ls -ld .*`  | 以长列表形式列出点文件(隐藏文件)                                          |
| lS    | `ls -1FSsh`  | 按大小排序列出文件,只显示大小和名称                                        |
| lart  | `ls -1Fcart` | 列出全部文件,按创建/修改时间倒序排列(最旧的在前)                          |
| lrt   | `ls -1Fcrt`  | 列出文件,按创建/修改时间倒序排列(最旧的在前)                              |
| lsr   | `ls -lARFh`  | 递归列出所有文件和目录                                                      |
| lsn   | `ls -1`      | 单列列出文件和目录                                                          |

### 文件处理

| 别名  | 命令                  | 说明                                                                            |
| ----- | --------------------- | ------------------------------------------------------------------------------- |
| rm    | `rm -i`               | 删除文件                                                                        |
| cp    | `cp -i`               | 复制文件                                                                        |
| mv    | `mv -i`               | 移动文件                                                                        |
| zshrc | `${=EDITOR} ~/.zshrc` | 快速打开 ~/.zshrc 文件                                                          |
| dud   | `du -d 1 -h`          | 以人类可读的形式显示当前位置下深度为 1 的文件大小                               |
| duf\* | `du -sh`              | 以人类可读的形式显示当前位置下所有文件的大小                                    |
| t     | `tail -f`             | tail 的简写,输出文件的末尾部分                                                 |

\* 仅当未安装 [`duf`](https://github.com/muesli/duf) 命令时才生效。

## 全局别名

这些别名可以在命令行的任意位置展开,也就是说,即使放在你输入的命令末尾也能使用。例如:

快速通过管道传给 less:

```zsh
$ ls -l /var/log L
# will run
$ ls -l /var/log | less
```

静默 stderr 输出:

```zsh
$ find . -type f NE
# will run
$ find . -type f 2>/dev/null
```

| 别名 | 命令                        | 说明                                                        |
| ---- | --------------------------- | ----------------------------------------------------------- |
| H    | `\| head`                   | 把输出通过管道传给 head,输出文件的开头部分                 |
| T    | `\| tail`                   | 把输出通过管道传给 tail,输出文件的末尾部分                 |
| G    | `\| grep`                   | 把输出通过管道传给 grep,搜索某个词                         |
| L    | `\| less`                   | 把输出通过管道传给 less,便于分页查看                       |
| M    | `\| most`                   | 把输出通过管道传给 more,便于分页查看                       |
| LL   | `2>&1 \| less`              | 把 stderr 写入 stdout,再传给 less                          |
| CA   | `2>&1 \| cat -A`            | 把 stderr 写入 stdout,再传给 cat                           |
| NE   | `2 > /dev/null`             | 静默 stderr                                                 |
| NUL  | `> /dev/null 2>&1`          | 同时静默 stdout 和 stderr                                   |
| P    | `2>&1\| pygmentize -l pytb` | 把 stderr 写入 stdout,再传给 pygmentize                    |

## 文件扩展名别名

这是一类特殊别名:当文件名被当作命令输入时就会触发。例如,如果把 pdf 扩展名别名到
`acroread`(一款流行的 Linux pdf 阅读器),那么运行 `file.pdf` 时就会用 `acroread` 打开该文件。

### 阅读文档

| 别名 | 命令       | 说明                               |
| ---- | ---------- | ---------------------------------- |
| pdf  | `acroread` | 用 acroread 打开文档               |
| ps   | `gv`       | 用 gv 打开 .ps 文件                |
| dvi  | `xdvi`     | 用 xdvi 打开 .dvi 文件             |
| chm  | `xchm`     | 用 xchm 打开 .chm 文件             |
| djvu | `djview`   | 用 djview 打开 .djvu 文件          |

### 列出压缩包内的文件

| 别名   | 命令        | 说明                              |
| ------ | ----------- | --------------------------------- |
| zip    | `unzip -l`  | 列出 .zip 文件内的文件            |
| rar    | `unrar l`   | 列出 .rar 文件内的文件            |
| tar    | `tar tf`    | 列出 .tar 文件内的文件            |
| tar.gz | `tar -ztf`  | 列出 .tar.gz 文件内的文件         |
| ace    | `unace l`   | 列出 .ace 文件内的文件            |

### 其他一些特性

- 使用变量 `$BROWSER` 指定的浏览器在终端中打开网址
- 使用变量 `$EDITOR` 指定的编辑器打开 C、C++、Tex 和文本文件
- 使用变量 `$XIVIEWER` 指定的图片查看器打开图片
- 使用 mplayer 打开视频和其他媒体
