# JFrog CLI

本插件为 [JFrog CLI](https://github.com/jfrog/jfrog-cli) 提供自动补全。

JFrog CLI 提供一个简单的接口,可以通过 [Artifactory](https://jfrog.com/artifactory)、[Xray](https://jfrog.com/xray)、[Bintray](https://jfrog.com/bintray) 和 [Mission Control](https://jfrog.com/mission-control) 各自的 REST API 自动化访问这些产品。

✅ 启用方式:把「jfrog」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。
