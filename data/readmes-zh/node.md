# node 插件

本插件添加 `node-docs` 函数,用于在 [Node.js](https://nodejs.org) 文档中打开指定章节(取决于已安装的版本)。

✅ 启用方式:把「node」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 用法

```zsh
# Opens https://nodejs.org/docs/latest-v10.x/api/fs.html
$ node-docs fs
# Opens https://nodejs.org/docs/latest-v10.x/api/path.html
$ node-docs path
```
