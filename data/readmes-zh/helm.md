# Helm 插件

本插件为 Kubernetes 包管理器 [Helm](https://helm.sh/) 提供补全和别名。

✅ 启用方式:把「helm」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 别名

| 别名  | 完整命令        |
| ----- | -------------- |
| h     | helm           |
| hin   | helm install   |
| hun   | helm uninstall |
| hse   | helm search    |
| hup   | helm upgrade   |
