# Spring Boot oh-my-zsh 插件

为所有 [Spring Boot](https://spring.io/projects/spring-boot) 命令添加自动补全选项。

✅ 启用方式:把「spring」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 提示

* 安装 Spring Cloud 插件:spring install org.springframework.cloud:spring-cloud-cli:1.0.2.RELEASE

## 参考

* Spring Boot: https://spring.io/projects/spring-boot
* Spring Boot CLI: https://docs.spring.io/spring-boot/docs/current/reference/htmlsingle/#cli
