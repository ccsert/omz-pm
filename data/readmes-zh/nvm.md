# nvm 插件

本插件为 [nvm](https://github.com/nvm-sh/nvm)(一个 Node.js 版本管理器)添加自动补全。
它还会自动 source nvm,因此你不需要在 `.zshrc` 里手动加载。

✅ 启用方式:把「nvm」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 设置

如果你把 nvm 安装在了 `$HOME/.nvm` 以外的目录,请设置并导出 `NVM_DIR`,使其指向你安装 nvm 的目录。

这些设置应写进你的 zshrc 文件,且位于加载 Oh My Zsh 之前:

- **`NVM_HOMEBREW`**:如果你是通过 Homebrew 安装的 nvm,且安装位置不是 `/usr/local/opt/nvm`,
  可以把 `NVM_HOMEBREW` 设置为你安装它的目录。例如,在 Apple Silicon 架构的 Mac 上,
  [Homebrew 安装在 `/opt/homebrew`](https://docs.brew.sh/Installation)。无论芯片架构如何,
  都可以用 `NVM_HOMEBREW=$(brew --prefix nvm)` 来获取 nvm 的安装目录。

## 自定义

#### 懒加载启动

这个选项可以推迟 nvm 的加载,直到你真正使用它,从而加快 zsh 的启动速度。它只会在使用时
才加载 nvm 脚本,并为 `node`、`npm`、`npx`、`pnpm`、`pnpx`、`yarn`、
`corepack` 以及 `lazy-cmd` 选项指定的命令创建包装函数;当你调用其中任意一个时,
nvm 会以默认版本被加载并运行。要启用它,可以把下面的代码片段加到 zshrc 中加载
Oh My Zsh 之前:

```zsh
zstyle ':omz:plugins:nvm' lazy yes
```

然后,要定义其他同样会触发 nvm 加载的命令,可以使用类似的语法,想加多少个都行:

```zsh
zstyle ':omz:plugins:nvm' lazy-cmd eslint prettier typescript ...
```

还会有一个 `_omz_nvm_load` 函数可用,用于只加载 `nvm` 而不执行任何其他触发命令。

#### `.nvmrc` 自动加载

注意:_如果与 `lazy` 同时使用,`autoload` 只会在 nvm 完成懒加载之后才开始生效_

设置之后,只要插件在当前工作目录中发现
[`.nvmrc` 文件](https://github.com/nvm-sh/nvm#nvmrc)(其中指明了要加载的 node 版本),
就会自动加载对应的 node 版本。做法与前面的选项类似,添加:

```zsh
zstyle ':omz:plugins:nvm' autoload yes
zstyle ':omz:plugins:nvm' silent-autoload yes # optionally remove the output generated by NVM when autoloading
```

注意:_这不会移除 `nvm` 本身的常规输出_
