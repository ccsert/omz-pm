# hitchhiker

本插件收录了道格拉斯·亚当斯(Douglas Adams)《银河系漫游指南》中的语录。

✅ 启用方式:把「hitchhiker」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 别名

- `hitchhiker`:使用 `fortune` 显示一条书中语录。
- `hitchhiker_cow`:使用 `cowthink` 显示一条书中语录。

```console
$ hitchhiker_cow
 _______________________________________
( "OK, so ten out of ten for style, but )
( minus several million for good        )
( thinking, yeah? "                     )
 ---------------------------------------
        o   ^__^
         o  (oo)\_______
            (__)\       )\/\
                ||----w |
                ||     ||
```

## 依赖要求

- `fortune` 和 `strfile`。
- `cowthink`(如果使用 `hitchhiker_cow` 命令则需要)。
