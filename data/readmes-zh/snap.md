# snap 插件

本插件为常用的 [snap](https://snapcraft.io/docs/getting-started) 命令设置别名。

## 别名

| 别名  | 完整命令 |
| --- | ---|
| sv | snap version |
| sf | snap find |
| si | snap install |
| sin | snap info |
| sr | snap remove |
| sref | snap refresh |
| srev | snap revert |
| sl | snap list |
| sd | snap disable |
| se | snap enable |
