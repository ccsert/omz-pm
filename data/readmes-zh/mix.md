# Mix 插件

本插件为 [Elixir 的 Mix 构建工具](https://hexdocs.pm/mix/Mix.html)提供补全。

✅ 启用方式:把「mix」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 受支持的任务类型

| 任务类型                 | 文档                                                     |
| ------------------------ | -------------------------------------------------------- |
| Elixir                   | [Elixir Lang](https://elixir-lang.org/)                  |
| Phoenix v1.2.1 及以下    | [Phoenix](https://hexdocs.pm/phoenix/1.2.1/Phoenix.html) |
| Phoenix v1.3.0 及以上    | [Phoenix](https://hexdocs.pm/phoenix/Phoenix.html)       |
| Ecto                     | [Ecto](https://hexdocs.pm/ecto/Ecto.html)                |
| Hex                      | [Hex](https://hex.pm/)                                   |
| Nerves                   | [Nerves](https://nerves-project.org/)                    |
| mix_test_watch           | [mix_test_watch](https://hex.pm/packages/mix_test_watch) |
