# multipass

本插件为 [multipass](https://multipass.run) 提供补全,以及 multipass 命令的别名。

✅ 启用方式:把「multipass」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 别名

| 别名   | 命令                                                                |
| ------ | ------------------------------------------------------------------- |
| `mp`   | `multipass`                                                         |
| `mpl`  | `multipass list`                                                    |
| `mpla` | `multipass launch`                                                  |
| `mpln` | `multipass launch --network en0 --network name=bridge0,mode=manual` |
| `mps`  | `multipass shell`                                                   |
| `mpsp` | `multipass stop`                                                    |
| `mpst` | `multipass start`                                                   |
