# catimg

一个在终端中显示图片的插件,使用 [posva](https://github.com/posva/catimg) 提供的
`catimg.sh` 脚本。

✅ 启用方式:把「catimg」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 依赖要求

- `magick convert`(ImageMagick)

## 函数

| 函数      | 说明                                     |
| -------- | ---------------------------------------- |
| `catimg` | 在终端中显示给定的图片                     |
