## Flutter 插件

Flutter 插件提供补全和一组实用的别名。

✅ 启用方式:把「flutter」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 别名

| 别名       | 命令                    | 说明                                                                       |
| :--------- | :---------------------- | :------------------------------------------------------------------------- |
| `fl`       | `flutter`               | flutter 命令的简写                                                         |
| `fla`      | `flutter analyze`       | 分析 flutter 代码                                                          |
| `flattach` | `flutter attach`        | 把 flutter 附加到一台开启了 observatory 的运行中的 flutter 应用             |
| `flb`      | `flutter build`         | 构建 flutter 应用                                                          |
| `flc`      | `flutter clean`         | 清理 flutter 项目                                                          |
| `flchnl`   | `flutter channel`       | 切换 flutter 频道(需要输入目标频道)                                        |
| `fldoc`    | `flutter doctor`        | 运行 flutter doctor                                                        |
| `fldvcs`   | `flutter devices`       | 列出已连接的设备(如有)                                                    |
| `flget`    | `flutter pub get`       | 安装依赖                                                                   |
| `fll`      | `flutter logs`          | 查看 flutter 日志                                                          |
| `flpu`     | `flutter pub upgrade`   | 升级依赖                                                                   |
| `flpub`    | `flutter pub`           | flutter pub 命令的简写                                                     |
| `flr`      | `flutter run`           | 运行 flutter 应用                                                          |
| `flrd`     | `flutter run --debug`   | 以调试模式运行 flutter 应用(默认模式)                                      |
| `flrp`     | `flutter run --profile` | 以 profile 模式运行 flutter 应用                                           |
| `flrr`     | `flutter run --release` | 以发布模式运行 flutter 应用                                                |
| `flt`      | `flutter test`          | 运行 flutter 测试                                                          |
| `flupgrd`  | `flutter upgrade`       | 根据当前频道升级 flutter 版本                                              |
