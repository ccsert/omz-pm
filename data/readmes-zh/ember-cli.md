# Ember CLI 插件

本插件为 [`ember-cli`](https://cli.emberjs.com/) 提供自动补全和别名。

✅ 启用方式:把「ember-cli」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 别名

| 别名  | 命令                 |
| ----- | -------------------- |
| `ea`  | `ember addon`        |
| `eb`  | `ember build`        |
| `ed`  | `ember destroy`      |
| `eg`  | `ember generate`     |
| `eh`  | `ember help`         |
| `ei`  | `ember install`      |
| `ein` | `ember init`         |
| `es`  | `ember serve`        |
| `et`  | `ember test`         |
| `ets` | `ember test --serve` |
| `eu`  | `ember update`       |
| `ev`  | `ember version`      |
