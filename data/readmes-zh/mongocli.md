# mongocli 插件

本插件为常用的 [mongocli](https://docs.mongodb.com/mongocli/stable/) 命令添加了若干别名。

✅ 启用方式:把「mongocli」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 别名

| 别名   | 命令                     | 说明                                    |
| ------ | ------------------------ | --------------------------------------- |
| `ma`   | `mongocli atlas`         | mongocli Atlas 命令的快捷方式。         |
| `mcm`  | `mongocli cloud-manager` | mongocli Cloud Manager 命令的快捷方式。 |
| `mom`  | `mongocli ops-manager`   | mongocli Cloud Manager 命令的快捷方式。 |
| `miam` | `mongocli iam`           | mongocli IAM 命令的快捷方式。           |
