# pm2 插件

本插件为常用的 [pm2](http://pm2.keymetrics.io/) 命令添加了若干别名和补全。

✅ 启用方式:把「pm2」加入 zshrc 的 plugins 数组(可用 omz-pm 一键完成)。

## 别名

| 别名   | 命令                 |
|--------|----------------------|
| p2s  | `pm2 start` |
| p2o  | `pm2 stop` |
| p2d | `pm2 delete` |
| p2r   | `pm2 restart` |
| p2i   | `pm2 list` |
| p2l   |  `pm2 logs` |
